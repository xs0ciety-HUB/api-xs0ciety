🚀 Download API v2

API serverless untuk download dari berbagai platform. Butuh API key di header x-api-key.

⚠️ Butuh API key? Hubungi admin untuk generate key. Kuota dihitung per request.

🔑 Cara Pakai

Header: x-api-key: sk_xxxxxxxxxxxxxxxx
   atau query string: ?apikey=sk_xxxxxxxxxxxxxxxx

📦 Available Endpoints

POST /api/v2/facebook

{"url": "https://facebook.com/watch?v=xxx"}

GET /api/v2/instagram

GET /api/v2/instagram?url=https://instagram.com/p/xxx&apikey=sk_xxx

POST /api/v2/tiktok

{"url": "https://tiktok.com/@user/video/xxx"}

POST /api/v2/twitter

{"url": "https://x.com/user/status/123456"}

POST /api/v2/youtube

{"url": "https://youtube.com/watch?v=xxx"}

POST /api/v2/spotify

{"url": "https://open.spotify.com/track/xxx"}

POST /api/v2/soundcloud

{"url": "https://soundcloud.com/user/track"}

POST /api/v2/upload

Content-Type: multipart/form-data
Field: file (wajib), time (1h/12h/24h/72h)

POST /api/v2/faceswap

multipart: source (image), target (image)
atau JSON: {"source_url": "...", "target_url": "..."}

POST /api/v2/voice-changer

multipart: file (audio), voice_id (optional)
